# Empirical Results

This directory contains compact result files from the 2023-2026 historical study.

## Included files

| File | Contents |
|---|---|
| `results_manifest.json` | Dataset/result counts, timing-audit status, and master-dataset SHA-256. |
| `directional_oos_metrics.csv` | Directional metrics for all four models across 2024 validation, 2025 holdout, and 2026 robustness. |
| `incremental_sentiment_comparison.csv` | Within-family market-plus-sentiment versus market-only differences. |
| `oos_predictions.csv` | Saved out-of-sample probabilities and targets. |
| `selected_hyperparameters.json` | Hyperparameters selected from the 2024 chronological validation period. |
| `calibration_metrics.csv` | Calibration intercept, slope, and expected calibration error. |
| `block_bootstrap_summary.csv` | Paired moving-block-bootstrap point differences and 95% intervals. |
| `garch_forecasts.csv` | One-step GARCH(1,1) volatility forecasts used by the risk overlay. |
| `garch_forecast_metrics.csv` | Period-level GARCH diagnostics. |
| `simulation_metrics.csv` | Transaction-cost simulation metrics for all four directional models, with and without GARCH scaling. |
| `paired_simulation_comparison.csv` | Within-family simulation differences. |

## Files kept local

The repository does not include the full historical GDELT headline store, per-headline FinBERT files, full article-level alignment table, generated master CSV, fitted model binaries, bootstrap replication draws, or full simulation paths.

These larger artifacts are generated by the source pipeline. The compact files in this directory provide the numerical outputs referenced in the documentation.

The master-dataset SHA-256 stored in `results_manifest.json` matches the value used by the directional experiment configuration.
