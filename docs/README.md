# Research Documentation

This directory contains the documentation for the 2023–2026 CSI 300 news-sentiment study.

Recommended reading order:

1. [Architecture](ARCHITECTURE.md) — pipeline structure and component roles.
2. [Data Card](DATA_CARD.md) — data sources, coverage, timestamp handling, and data limitations.
3. [Data Dictionary](DATA_DICTIONARY.md) — definitions for the master session dataset.
4. [Experiment Design](EXPERIMENT_DESIGN.md) — chronological split, feature groups, models, and evaluation procedure.
5. [Results](RESULTS.md) — out-of-sample forecasting, calibration, bootstrap, GARCH, and simulation results.
6. [Model Card](MODEL_CARD.md) — model scope, features, evaluation, and limitations.
7. [Limitations](LIMITATIONS.md) — data, model, and simulation limitations.
8. [Reproducibility](REPRODUCIBILITY.md) — build and evaluation sequence.
9. [Research Scope](RESEARCH_SCOPE.md) — concise description of the study and its coverage.
10. [Academic Disclosure](ACADEMIC_DISCLOSURE.md) — explicit claims, limitations, and research-use disclosure.
11. [Oral Defense Guide](ORAL_DEFENSE_GUIDE.md) — interview-ready project summary, methodological defense, and likely questions.

Compact empirical result files are available under `results/`. Large generated datasets and model binaries remain local.
