# Institutional News Ingestion Certification

## 1. Executive Summary
This document formally certifies the operational resilience and governance topology of the Module 1 News Ingestion Subsystem (GDELT). The ingestion layer has been fundamentally rebuilt to adhere to strict institutional requirements, ensuring that upstream data failures cannot quietly pollute the downstream deterministic infrastructure.

## 2. Ingestion Determinism & API Resilience
- **Query Hardening**: The API payload now utilizes deterministic keyword grouping, ensuring identical macro financial framing (`(China OR PBOC OR Beijing) (economy OR "stock market" OR "financial markets" OR regulation) sourcelang:english`).
- **Schema Validation**: The payload structure (`seendate`, `title`, `domain`) is actively enforced. Missing fields immediately trigger `SAFE MODE`.
- **Temporal Governance**: All datetime extraction explicitly mandates strict CST (UTC+8) localization using `datetime.timezone.utc`, eradicating local machine-time drift.

## 3. Operational Observability (Read-Only)
- **API Diagnostics**: Every network request generated by Module 1 logs its exact timestamp, URL hash, status code, byte size, and extraction count to `logs/gdelt_response_audit.jsonl`.
- **Extraction & Quality Manifests**: A permanent lineage ledger (`outputs/news_ingestion_manifest.csv` and `outputs/news_quality_manifest.csv`) ensures the ingestion state can be forensically audited for source concentration, boilerplate ratios, and entropy over time.

## 4. SAFE MODE Integration
The ingestion subsystem is now completely wired into the global `SAFE MODE` pipeline. The following violations trigger an immediate pipeline halt (preventing silent PnL degradation):
- Zero articles extracted (`get_latest_news`).
- Malformed JSON API payloads.
- Schema drift or missing target data points.
- Frozen/Stale timestamps indicating an unresponsive GDELT endpoint.

## 5. Subsystem Fallback Governance
- The system includes a strictly sandboxed multi-source fallback framework (`module1_fallback_sandbox.py`).
- **CRITICAL RESTRICTION**: The fallback systems (NewsAPI, RSS, AlphaVantage) possess ZERO autonomous execution authority and cannot override GDELT. The architecture prioritizes data integrity and deterministic suspension over unverified alternative sources.
