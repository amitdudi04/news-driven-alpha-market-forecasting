# Project Limitations
## Dataset limitations
The project operates under severe public API limitations (GDELT HTTP 429 block). The dataset is strictly bound to a 104-day news archive.

## Walk-Forward Constraints
The walk-forward evaluation sample size is 21 days out-of-sample. This is statistically insufficient to prove out-of-sample edge or long-horizon structural returns.

## Operational Status
The system has no live capital deployed. It is authorized for Paper trading only. The SAFE MODE conservatism is extremely high, defaulting to flat positions under uncertainty.

## Future work
Future work requires building a multi-year archive, acquiring a larger historical dataset, and undergoing longer paper trading. Real deployment can only occur after statistical significance is established.
