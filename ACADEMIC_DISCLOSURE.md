# Academic Disclosure

This repository presents a student research project in financial forecasting.

- The committed news/sentiment sample currently begins on **2026-04-22**.
- Earlier development seed rows are not part of the public research sample.
- The clean history is still short, so the repository does **not** claim a statistically established or durable trading edge.
- Historical model evaluation is designed to use chronological expanding-window splits.
- A final model may be refit on all labelled observations for the next paper-trading prediction, but that refit is kept separate from the out-of-sample evaluation.
- The project is for research and educational use only; no live-capital execution is included.
